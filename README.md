# 웹 해커 포트폴리오

열정적이고 패기있는 웹 보안 연구원 포트폴리오 웹사이트입니다.

## 📥 PDF로 저장하는 방법

포트폴리오를 PDF로 저장하여 제출하고 싶으신가요? 다음 방법을 사용하세요:

### 방법 1: 브라우저에서 직접 인쇄 (권장)

1. **index.html** 파일을 브라우저에서 엽니다
2. 브라우저 메뉴에서 **인쇄** (Ctrl+P 또는 Cmd+P)를 선택합니다
3. 다음 설정을 사용하세요:
   - **대상**: PDF로 저장
   - **용지 크기**: A4
   - **여백**: 기본값
   - **배경 그래픽**: ✅ 체크 (중요!)
   - **색상**: 색상 인쇄
4. **저장** 버튼을 클릭합니다

### 브라우저별 설정

#### Chrome / Edge
1. Ctrl+P (Windows) 또는 Cmd+P (Mac)
2. 대상: "PDF로 저장" 선택
3. **추가 설정**을 펼치고:
   - ✅ 배경 그래픽 체크
   - 용지 크기: A4
   - 여백: 기본값
4. 저장 클릭

#### Firefox
1. Ctrl+P (Windows) 또는 Cmd+P (Mac)
2. "Microsoft Print to PDF" 또는 "PDF로 저장" 선택
3. **페이지 설정**에서:
   - ✅ 배경색 및 이미지 인쇄 체크
   - 용지 크기: A4
4. 확인 후 저장

#### Safari (Mac)
1. Cmd+P
2. 왼쪽 하단의 **PDF** 버튼 클릭
3. "PDF로 저장" 선택
4. 저장 위치 지정 후 저장

### 💡 팁

- **배경 그래픽 옵션을 반드시 켜세요!** 이 옵션이 꺼져 있으면 색상과 디자인이 사라집니다.
- PDF로 저장하면 불필요한 요소(네비게이션, 버튼 등)는 자동으로 숨겨집니다.
- 인쇄 미리보기에서 레이아웃을 확인한 후 저장하세요.
- 페이지가 잘리지 않도록 자동으로 페이지 구분이 설정되어 있습니다.

## 🚀 웹사이트 사용법

### 로컬에서 실행
```bash
# 파일을 더블클릭하거나
# 브라우저에서 index.html 파일을 열면 됩니다
```

### 주요 기능
- **반응형 디자인**: 모바일, 태블릿, 데스크톱 모두 지원
- **인터랙티브 요소**: 타이핑 애니메이션, 스크롤 효과
- **모달 시스템**: 교육 및 프로젝트 클릭 시 상세 정보 표시
- **다크 테마**: 웹 해커다운 사이버 보안 느낌

### 커스터마이징

본인의 정보로 수정하려면:

1. **index.html** 파일을 텍스트 에디터로 열기
2. 다음 섹션 수정:
   - About Me (15-50번 줄)
   - 학력/경력 (55-80번 줄)
   - 교육 과정 (88-137번 줄)
   - 활동 내역 (149-202번 줄)
   - 프로젝트 (211-279번 줄)
   - 연락처 (287-301번 줄)

3. **script.js**에서 모달 상세 내용 수정 (44-194번 줄)
